# Inmotion Hosting Website E2E Automation Project
This project automates the search for a domain and adds web hosting plan for [InMotion Hosting](https://www.inmotionhosting.com/web-hosting) website using Selenium WebDriver and Java.

# Task Scope
## This automation covers:

- Launching the browser and validating homepage title  
- Opening domain page and searching for a specific domain  
- Checking if the domain is available or not  
- Checking the price of the domain  
- Opening web hosting plan page and selecting a specific hosting plan  
- Going to cart and checking the total price of domain and web hosting plan  
- Refreshing the page and checking them again  
- Checking error message after entering an invalid domain
